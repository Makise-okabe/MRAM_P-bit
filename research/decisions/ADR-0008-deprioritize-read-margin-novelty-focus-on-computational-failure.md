# ADR-0008 — Explicitly avoid sensing/read-margin optimization as core FYP novelty
**2026-11-05 | User relays Prof Kelvin Fong's guidance:** steer away from sensing and read margin because the field is crowded. Treat this as a hard research-scope constraint unless professor later clarifies. **Status:** retire N1 as the core novelty hypothesis, not as physical background characterization.

## Why previous N1 was too close
The 2026-11-05 [N1 margin predictor](../novelty/2026-11-05-N1-calibration-budgeted-ADC-decision-boundary-predictor-CANDIDATE.md) focused on predictive distance to ADC count boundaries, reference/bit depth selection, calibration and near/suffix-Q corrections. Although unlike single-cell P/AP memory reading it involved multi-count analog MAC, its contribution remained **readout/sensing-margin prediction and optimization**. Rebranding it 'failure-boundary predictor' does not avoid that prior-art region. Hardware read/ADC margin research must be a measurement tool and reliability input to computational-level research, NOT the claimed new invention.

Close work verified:
- DIB-CIM (Chen et al, IEEE TCAS-I early-access 31 Aug 2026, DOI 10.1109/TCSI.2026.3726936) dynamically changes MRAM CIM input block and ADC resolution based on bit significance/input distribution.
- Trust, but Verify (Nezhadi et al, IOLTS 2026, DOI 10.1109/IOLTS69666.2026.11633847) already performs double-reference sensing plus selective recomputation.
- NanoCiM (Matsui et al, IEEE TCASAI 2026, DOI 10.1109/TCASAI.2026.3661436) uses weight-aware address scrambling for IR-drop reduction.
- 2026 Journal of Semiconductors review (DOI 10.1088/1674-4926/26060006) classifies error-aware mapping, scheduling, cross-layer propagation and adaptive hardware methods as existing areas. **Consequently even moving to system algorithms does not confer novelty automatically.**

## Reframe research at computation/inference layer, not circuit sensing
**Candidate investigation, not approved/proven original:** How do *spatially structured and temporally/persistently correlated* MTJ-array count errors combine across a **signed W4A8 bit-plane inference** pipeline to cause actual logits/class changes; can a **precisely defined, cost-matched compute-level intervention** outperform conventional fixed-bit allocation, bit-significance-prioritized scheduling, generic adaptive CIM and simple Q/current correction in a physically grounded regime?

Potential unproven mathematical mechanism: if decoded bit-plane read errors are `e_i` and signed significance factors are `c_i`, reconstructed arithmetic output error is `E = Σ_i c_i e_i`. Across persistent device chips/input patterns, `Var(E)=c^T Σ_e c`: covariance/correlation may materially change final error compared with IID/additive models, and downstream neural sensitivity may amplify or suppress it. This is a **hypothesis**, not a novelty claim and must not resurrect the unsuccessful IID synthetic E03 covariance score as established.

**First gate:** full frozen W4A8 trained network plus physically justified GF 2T1MTJ/PEX read operation and actual per-block error kernel. Compare independent IID error injection vs held-out **joint, physically measured** read-error vectors with the SAME marginal count-error rates and identical read budgets. Report classification flips, logits and margins (classification margin, NOT ADC sensing margin), and whether covariance produces a distinct observed failure phenomenon. An ordinary model matching them gives a null result.

**Second gate only if first passes:** pre-register one concrete compute-level policy (e.g., reduce full-network classifier-decision errors with a fixed per-layer bit-plane budget or selective digital fallback), tuned and cost-matched versus bit significance, input activity, fixed precision, original Q calibration, DIB-style adaptation, standard selective recompute. Never simply repeat an unchanged deterministic IR-drop read and assume it fixes persistent errors. Work must avoid dependence on knowing the true count/logit at runtime.

**Physical constraint:** The successful E22–E24 GF compact-model current cases used a 32-branch single access-NFET + student static MTJ, assumed wire R. They are NOT the user's earlier local-floating 4×4 2T1MTJ PEX or validated full 256×256 physically extracted macro. Recover 4×4 DSPF, validate true parallel-CIM read, then realistic multi-column error kernel before task-level conclusions. If original network weights/biases or PEX kernel unavailable, note a blocking input instead of inventing end-to-end results.
