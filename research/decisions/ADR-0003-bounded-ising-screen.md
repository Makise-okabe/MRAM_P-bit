# ADR-0003: Consolidate candidates and add a bounded Ising diagnostic

Date: 4 November 2026 (Singapore)

Status: accepted experiment organization; no final topic or novelty pass.

Context: the user supplied Claude revision 15 and requested a consolidated GitHub plan
to begin experiments and eliminate candidates. The new Ising figures are unreproduced
illustrative claims based on an excluded small-group-like model. Incremental local
fields are confirmed prior art. A shared error model is not by itself a new unified method.

Decision: retain F3's decoded-covariance mapping as the main development candidate. Add
F7a/E09B persistence and field-operator diagnostics and a conditional E09C exact-target
pilot, with E09A software controls first. F7b refinement remains a reserve. Permit an
Ising companion only after a distinct useful question, common mechanism/method and
scope fit survive the small checks; do not commit a three-to-four-week chapter or large
graph campaign now. All other families remain reserves at the roles in the queue.

Completed engineering evidence: E09A checks true graph objectives, exact small-graph
optima, full/incremental trajectory equivalence and a two-flip cache-residual identity.
Six added tests and ten existing tests pass. No noisy-target solver result is introduced.
The target-kernel preflight remains blocked by missing model and temporal-noise evidence.

Consequences: the [queue](../04_screening_queue.md) gives readiness, commands and stopping
criteria. The [source review](../reviews/2026-11-04-claude-revision15.md) records the
temperature-floor/cache-drift alternative, matched-marginal requirements, strong digital
incremental baseline and TTS/statistical corrections. ADR-0001/0002 and archive boundaries
remain in force. Report only the evidence class actually obtained.
