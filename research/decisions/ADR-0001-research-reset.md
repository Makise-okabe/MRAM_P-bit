# ADR-0001 - Archive prior phase and start target-array pathfinding

Date: 2026-11-03 (Asia/Singapore). Status: adopted for repository organization at the user's request.

## Context

The current discussion has several candidate methods, but no established novelty pass.
The user wants all ideas recalled, a deeper literature audit, bounded experiments and an
ongoing record for CA2. The physical target is 256 x 256. Existing trial results are excluded
from new target evidence. The former report and unmerged research branches must remain traceable.

## Decision

Archive the complete pre-reset main tree unchanged and retain its commit on a named archive
branch. Record all existing branch heads. Start a fresh root report and an active research
tree with stable idea/family/experiment/claim IDs. Keep seven method families as competitors.
Begin with exact software verification and real-trace structure, then a small target-array
physical gate. Do not select a winning method from a toy failure-rate demonstration.

## Consequences

Past work is preserved but does not enter the fresh results chapter. Generic code can be
audited for reuse. Physical modelling, licensed simulator execution and final supervisory
scope remain to be established. No new supervisor endorsement, large evaluation or
publication-level originality is claimed.

## Next decision

After E01 and E02 evidence plus full closest-work inspection, select one main candidate and
one backup, state their exact contribution and freeze the smallest strong comparison.
