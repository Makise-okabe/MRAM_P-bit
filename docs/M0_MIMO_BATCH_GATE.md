# M0 BPSK MIMO batch BER/ML smoke test — new evidence only

This is E1 ideal-device software, not a low-order FP or nonideal-MRAM result. Independently seeded complex Rayleigh H, transmitted BPSK x and AWGN n are generated by `m0_mimo_reference.frame`. Frames with different channel seeds are independent pseudorandom draws. SNR points with the same frame seed are **paired**, not independent, because the underlying H/x and standardized noise realization are reused.

All (2^{N_t}) candidate states are scored against independent original ML residual `||y-Hs||^2` at Nt<=16 to obtain the exact reference. The same frame is sampled with a fixed-beta ideal Gibbs baseline; choose its best **post-burn-in** recorded state by original residual. This is a modest software correctness/BER pilot, not time-to-first-target and not a good macro cost or PT comparison.

Outputs per SNR: exact ML BER and Gibbs-best BER **against transmitted bits**, Gibbs-best frame hit rate of exact ML (not BER), average original residual gap, attempted Gibbs spin-update counts. Every frame's H, y, transmitted x, sigma² and seed are serialized; script/source SHA256 and non-overwriting manifests retained.

Smoke command:
```bash
python3 -m unittest discover -s tests -v
python3 experiments/m0_mimo_batch.py --tx 4 --rx 4 --snrs 0,5,10,15 --frames 32 --burnin 1000 --records 200 --thin 5 --output results/m0_mimo_snr_pilot_001
```

32 frames × 4 bits = 128 transmitted bits per SNR: **too few for a precise BER claim**. No CI/novelty conclusions; use this to verify consistent BER/SNR trend, file provenance, and a nondegenerate M0 task. Freeze full M1 frame count, calibration vs held-out populations, absolute BER/ML gap criteria and uncertainty before quantitative FP4/FP6/FP8 comparison. A later distinct M0 sub-gate must validate the target solver's time-to-target and device-response provenance. Parasitic interconnect, old CIM and historic TSP/MaxCut are out of active scope.
